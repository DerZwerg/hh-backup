Datenschutzerklärung – hh-pve01 Backup

Diese Anwendung wird ausschließlich von ihrem Eigentümer für private Backups seines eigenen Google Drive genutzt. Sie greift nur auf Dateien zu, die sie selbst angelegt hat (Google-Berechtigung „drive.file“). Es werden keine Daten an Dritte weitergegeben, keine Daten anderer Personen verarbeitet und keine Analyse- oder Tracking-Dienste verwendet. Die gesicherten Daten werden vor dem Hochladen verschlüsselt.

Kontakt: über das GitHub-Profil DerZwerg.

Privacy Policy

This application is used solely by its owner for private backups to his own Google Drive. It only accesses files it created itself (scope "drive.file"). No data is shared with third parties, no data of other people is processed, and no analytics or tracking is used. Backup data is encrypted before upload. Contact: GitHub profile DerZwerg.
